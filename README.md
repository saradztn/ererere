# R ♥ S — قصتنا

موقع شخصي من رؤوف الى سارة
تاريخ الاعتراف 19.08.2026

---

## كيف تشغل الموقع

افتح `index.html` مباشرة في المتصفح
او شغل سيرفر محلي

```
cd R-S-Our-Story
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`

الموقع يشتغل محليا بالكامل
ما يرفع اي صورة ولا محادثة لاي مكان خارجي
ما فيه تتبع ولا اعلانات ولا خطوط من الانترنت

## اهم شيء تسويه الحين — الصور

### 1. صوركم

حط الصور في `assets/images/memories/` بهذه الاسماء

| الملف | وين يظهر |
|---|---|
| `sara-01.jpg` | الهيرو — الصورة الكبيرة |
| `raouf-01.jpg` | الهيرو — الصورة الاصغر |
| `memory-01.jpg` | الفصل 02 |
| `memory-02.jpg` | الكولاج — الفصل 07 |
| `memory-03.jpg` | الكولاج — الفصل 07 |
| `memory-04.jpg` | الكولاج — الفصل 07 |
| `memory-05.jpg` | المعرض |
| `game-01.jpg` | الفصل 06 |
| `game-02.jpg` | الفصل 06 |

**اي صورة ما تحطها المكان يبقى فارغ بشكل هادئ ومقصود**
ما راح تشوف صورة مكسورة ابدا

### 2. المحادثة

المحادثة **ما عادت صورة**
اعدت بناءها كنص مصمم بخطوط الموقع والوانه
ما تبين انها screenshot ابدا والجودة صارت حادة على اي شاشة

الكلام منقول حرف بحرف
نفس الرسائل نفس الايموجي نفس الوقت 12:51

تعدلها او تزيد رسائل من `js/script.js`

```js
const chatThread = [
  { who:"out", text:"..." },   // out = رؤوف
  { who:"reply", text:"تم الرد عليك" },
  { who:"in",  text:"..." }    // in  = سارة
];
```

الصورة الاصلية محفوظة في `assets/images/conversations/`
لكنها ما تظهر في الموقع
لو حبيت ترجعها للمعرض شيل التعليق عن الجزء المعلم في `script.js`

### 3. الاغاني

فيه اغنيتين بيانو هادئتين جاهزتين في `assets/music/`

| الملف | المصدر | الرخصة |
|---|---|---|
| `our-song.mp3` | Unnecessarily yearning and wistful piano music | CC BY-ND 4.0 |
| `song-02.mp3` | westward (v4) | CC BY 4.0 |

ما فيه تشغيل تلقائي — سارة هي اللي تضغط الزر
الصوت يطلع بالتدريج بدل ما يزعجها
زر `›` ينقل للاغنية الثانية والاغاني تدور تلقائيا

**تبي تحط اغنيتكم انتم**
بدل `our-song.mp3` بملفك وخلاص
او زد اغاني في `playlist` داخل `js/script.js`

```js
const playlist = [
  { src:"assets/music/our-song.mp3", name:"اغنيتنا" },
  { src:"assets/music/song-02.mp3",  name:"اغنية ثانية" }
];
```

## كيف تعدل النصوص

كل شيء في اول `js/script.js`

### رسالة الحب

```js
const loveLetter = [
  { text: "سارة" },
  { text: "يمكن هذا الموقع مجرد صفحة على الانترنت" },
  { text: "احبك يا سارة", big: true }
];
```

`big: true` يخلي السطر كبير وبلون مختلف

### ذكرى جديدة في المعرض

```js
const memories = [
  { date: "19.08.2026", title: "الاعتراف",
    image: "assets/images/memories/memory-05.jpg",
    caption: "اليوم اللي قلت لك فيه كل شيء" }
];
```

## قاعدة الكتابة العربية

مطبقة على كل نص في الموقع

- بدون تشكيل نهائيا
- الالف دايما `ا` — ما فيه `أ` ولا `إ` ولا `آ`
- علامات ترقيم قليلة جدا
- جمل قصيرة وطبيعية

لو زدت نص جديد خله على نفس الطريقة

## الخطوط

8 خطوط TTF حقيقية ومرخصة (SIL Open Font License) محملة محليا

| الخط | الوظيفة | عربي |
|---|---|---|
| `font-01-editorial-serif` — Cormorant Garamond | لاتيني editorial | لا |
| `font-02-elegant-arabic-serif` — Amiri | نصوص القصة والرسالة | نعم |
| `font-03-handwritten` — Caveat | التواقيع | لا |
| `font-04-modern-sans` — Tajawal | الواجهة والازرار | نعم |
| `font-05-condensed` — Archivo Narrow | الارقام الكبيرة `19` | لا |
| `font-06-mono` — JetBrains Mono | metadata و timestamps | لا |
| `font-07-display-arabic` — Aref Ruqaa | العناوين الضخمة | نعم |
| `font-08-humanist-sans` — Cairo | النصوص الطويلة | نعم |

الخطوط اللي ما تدعم العربية مستخدمة فقط للارقام واللاتيني
عبر `unicode-range` في CSS
يعني مستحيل يطلع نص عربي بخط ما يدعمه
